# Product

## Register

brand

## Platform

web

## Users

SCCA members and event participants — autocross, rallycross, and time-trial competitors who check event info, register for events, and view results on ksscca.org. Secondary: prospective members and the general public researching the club.

## Product Purpose

Cones is the design system backing the ksscca.org rebuild: a component library (Storybook, React Aria + Tailwind CSS 4) that gives the Kansas Region SCCA site a coherent, motorsport-flavored visual identity in place of the current KingSize-themed WordPress site. Success looks like a site that reads as fast, credible, and specifically motorsport — not a generic club-website template — while staying accessible and fast to load on event weekends.

## Positioning

A regional motorsport club site that actually feels like motorsport — bold, condensed, poster-and-timing-screen typography instead of default WordPress theme chrome.

## Conversion & proof

- Primary and secondary CTA: Register for an event (primary); View results (secondary).
- The line a visitor remembers after 10 seconds: "This club takes racing seriously — and it shows in the site."
- Belief ladder: This is a real, active regional SCCA club → Events are current and easy to find → Registering and checking results is fast, not a chore.
- Proof on hand: none collected yet — event history, results archives, and photos live on the current site and haven't been migrated in.

## Brand Personality

Bold, vintage, Americana. Leans into the Staatliches poster/heritage-decal feel — nostalgic motorsport, gas-station-sign and old-decal energy — paired with Rajdhani's technical, timing-screen edge for secondary content, and Barlow for body/UI so the racing flavor doesn't fight legibility on result tables and forms.

## Anti-references

Generic corporate SaaS: no purple-to-blue gradients, no Inter-everywhere, no cards nested in cards, no rounded-square icon tile above every heading. This should never read as a dashboard template with a checkered-flag icon slapped on.

## Design Principles

- Motorsport typography does the branding work — bold display heads and technical subheads, not decoration layered on top of a generic template.
- Legible under pressure — results tables, event details, and forms stay in a plain, high-contrast body face (Barlow) regardless of how bold the headlines get.
- One accent, used sparingly — cone orange is the single primary action color; the status palette (blue/green/purple/red) is reserved for state, not decoration.
- Real content over placeholder chrome — no lorem ipsum feel; copy should read like an actual results page or event listing.

## Accessibility & Inclusion

WCAG AA baseline: 4.5:1 text contrast minimum, full keyboard navigation, proper heading hierarchy. (Known gap as of 2026-07-14: the primary orange Button variant's white-on-#d97706 text is only 3.2:1 — flagged by the Impeccable detector, not yet fixed.)
